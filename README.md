🩺 Disease Detection & Health Monitoring Web App

This project is a React-based health assistance web application designed to help users identify possible diseases based on selected symptoms and health parameters.
It also includes an Expert Mode and heart rate measurement support, providing a more advanced and interactive user experience.

The application is built with modern frontend technologies and supports Progressive Web App (PWA) features for better accessibility.

🌐 Live Demo

🔗 https://disease-seven.vercel.app/



⭐ Features

🧠 Disease Prediction Based on Symptoms
Users can select symptoms to identify possible diseases using predefined expert data.

🧑‍⚕️ Expert Mode
An advanced mode that provides enhanced disease evaluation logic for more accurate insights.

❤️ Heart Rate Measurement Support
Allows users to input heart rate values to assist in health condition analysis.

📊 Dynamic Result Display
Displays disease-related information instantly based on user input.

⚛️ Component-Based Architecture
Built using React for modular, reusable, and maintainable components.

📱 Progressive Web App (PWA)
Supports PWA features such as installability and offline-ready behavior.

🎨 Modern & Responsive UI
Styled using Tailwind CSS for a clean, responsive, and user-friendly interface.

⚡ Fast Performance with Vite
Optimized development and build performance using Vite.

🛠️ Tech Stack

Frontend: React (JavaScript)

Build Tool: Vite

Styling: Tailwind CSS

Data Handling: JavaScript (Expert Data Logic)

PWA Support: Service Worker

Version Control: Git & GitHub

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/AKYADAV-73749/disease.git
cd disease


Install dependencies:

npm install


Run the project locally:

npm run dev
